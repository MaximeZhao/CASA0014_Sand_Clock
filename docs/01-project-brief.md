# 01 — Project brief

## Aim
Create an approachable physical interaction for controlling classroom light through the metaphor of moving sand and passing time.

## Starting point
The initial proposal was a wireless magic wand using movement to select light colours. Hardware availability, beginner implementation effort and the need for a clear interaction led to alternatives including an origami fortune teller, a light seesaw, touch-based objects and a light hourglass.

## Selected concept
A handheld object turns motion into a remotely displayed sand animation. Turning it over reverses the flow; shaking disturbs it; a separate touch input freezes and resumes time.

## Constraints
- Arduino IDE and beginner-accessible construction methods.
- Existing MKR WiFi 1010 and available lab sensors.
- A 72-pixel display represented as a 12×6 web grid.
- Cardboard/transparent sheet enclosure; retain breadboard for current assembly.
- USB power after incompatible battery connectors blocked the battery route.

## Success criteria
The user can distinguish flip, shake and touch without instructions becoming complicated; the full transfer lasts approximately 30 active seconds; and the physical construction does not introduce intermittent connections or block touch and USB access.
